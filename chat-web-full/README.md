# OpenNemesis Chat Web Full

Cliente web completo (no embebido) para OpenNemesis-Live.

## Setup

```bash
npm install
cp .env.example .env.local
# Edita .env.local con tus credenciales de LiveKit

npm run dev
```

## Features

- Interfaz completa en pantalla (sin burbuja flotante)
- Voz en tiempo real (microfono)
- Chat textual
- Camara o pantalla compartida (una fuente visual activa)
- Conexion directa con LiveKit Agent
